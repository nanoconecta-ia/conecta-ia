# Conecta.IA

Site inteligente que conecta ERPs (piloto: Bling) a uma loja online, de forma autônoma: o lojista cadastra no ERP uma vez, e o produto aparece no site, para venda online ou como catálogo com atendimento pelo WhatsApp.

- Projeto isolado dos demais.
- Faz parte da organização **NanoConecta.ia**, que reúne dois produtos independentes:
  - 01 — **NanoShell IA**
  - 02 — **Conecta.ia**: plataforma de site com inteligência artificial e indexador.
- Banco: Supabase, projeto `conecta-ia` (plano gratuito no piloto).
- Detalhes: [`CLAUDE.md`](CLAUDE.md) (regras do projeto) e [`docs/ARQUITETURA.md`](docs/ARQUITETURA.md) (arquitetura e decisões em aberto).

Status: em definição. Nada de produção foi publicado.

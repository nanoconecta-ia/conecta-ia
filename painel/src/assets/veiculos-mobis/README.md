# Imagens de veículos da loja Mobis

Recortes das imagens enviadas pelo proprietário da Mobis em 16/11/2026 como exemplo do
veículo correto de cada modelo. Fundo branco, proporção 4:3, sem redimensionar para cima.

| Arquivo | Modelo |
|---|---|
| `hyundai-hr.webp` | Hyundai HR |
| `kia-bongo-k2500.webp` | Kia Bongo K2500 |
| `mitsubishi-l200.webp` | Mitsubishi L200 |

- Uso ilustrativo: a imagem identifica o modelo, não o ano, a versão nem a aplicação da peça.
- Origem e direito de uso das fotografias: **a confirmar pelo proprietário** (aparentam ser
  imagens de divulgação das montadoras).
- Um cartão de modelo só recebe imagem quando há fotografia do veículo correto. Nunca repetir
  a imagem de um modelo em outro.
